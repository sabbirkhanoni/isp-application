# চালু করার চেকলিস্ট (Go-live)

আসল গ্রাহক তোলার আগে এই ক্রমে করুন। প্রতিটি ধাপে অ্যাডমিন → **সিস্টেম চেক** পাতা খুলে সবুজ/হলুদ দেখুন।

## ক. সার্ভার ও নিরাপত্তা

- [ ] Render-এ `BACKGROUND_JOBS=true`, `ROUTER_SECRET` (১৬+ অক্ষর) দেওয়া আছে
- [ ] UptimeRobot প্রতি ৫ মিনিটে `/health` দেখছে
- [ ] GitHub-এ ব্যাকআপ সিক্রেট দেওয়া, একবার হাতে চালিয়ে সবুজ দেখেছেন
- [ ] ব্যাকআপ চাবি (age private key) দুই জায়গায় রাখা
- [ ] একবার রিস্টোর পরীক্ষা (`docs/backup-and-restore.md`)
- [ ] প্রথম অ্যাডমিনের পাসওয়ার্ড বদলানো, স্টাফের জন্য আলাদা অ্যাকাউন্ট

## খ. রাউটার (প্রথমে একজন টেস্ট গ্রাহকে)

- [ ] রাউটার যোগ করে "সাড়া দিচ্ছে" দেখেছেন (সিস্টেম চেক → রাউটার সবুজ)
- [ ] `ROUTER_DRY_RUN=true` রেখে টেস্ট গ্রাহক সাসপেন্ড/চালু করে লগে দেখেছেন
- [ ] `ROUTER_DRY_RUN=false` করে একই টেস্ট গ্রাহকে আসল সাসপেন্ড/চালু পরীক্ষা
- [ ] রাউটার তুলনা পাতায় (Compare) রাউটারে আছে কিন্তু সিস্টেমে নেই এমন ইউজার দেখে নিয়েছেন

## গ. এসএমএস

- [ ] প্রোভাইডার বেছে `SMS_DRIVER=http`, `SMS_API_URL`, `SMS_API_KEY`, `SMS_SENDER_ID` দিয়েছেন
- [ ] নিজের নম্বরে টেস্ট গ্রাহক খুলে পেমেন্ট এন্ট্রি দিয়ে বার্তা পেয়েছেন
- [ ] বার্তার লেখা (অ্যাডমিন → এসএমএস বার্তা) পছন্দমতো করেছেন
- [ ] `OWNER_PHONE` দিলে ১ তারিখে মাসিক সারাংশ আসবে

## ঘ. গ্রাহকের তথ্য তোলা

- [ ] পুরোনো গ্রাহক CSV ইমপোর্ট (Customers → Import), আগে "পরীক্ষা" তারপর "চূড়ান্ত"
- [ ] সিস্টেম চেক → "ভুল বা দুবার থাকা তথ্য" ফাঁকা (বা সব দেখে ঠিক করা)
- [ ] ডেটা এক্সপোর্ট নামিয়ে পুরোনো খাতার সাথে ১০–২০ জনের নাম, প্যাকেজ, বকেয়া মিলিয়েছেন

## ঙ. বিকাশ ও বিলিং

- [ ] আসল বিকাশ স্টেটমেন্ট CSV ইমপোর্টে কলাম ঠিকমতো ধরছে কি না একটি ছোট ফাইলে পরীক্ষা
- [ ] মাসের ১ তারিখের আগে সব গ্রাহক ACTIVE/SUSPENDED ঠিক আছে
- [ ] ১ তারিখে ইনভয়েস তৈরি হয়েছে (সিস্টেম চেক → "এ মাসের ইনভয়েস")
- [ ] বকেয়া হলে নিজে থেকে সাসপেন্ড চান কি না ঠিক করে `AUTO_SUSPEND` সেট (প্রথম মাস বন্ধ রাখাই ভালো)

## চ. চালুর পর প্রথম সপ্তাহ

- [ ] প্রতিদিন সিস্টেম চেক ও কার্যকলাপ লগ একবার দেখুন
- [ ] সপ্তাহ শেষে ব্যাকআপ সবুজ কি না দেখুন
